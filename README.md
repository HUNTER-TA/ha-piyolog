# ha-piyolog — ぴよログ (PiyoLog) for Home Assistant

[![HACS Custom](https://img.shields.io/badge/HACS-Custom-41BDF5.svg)](https://hacs.xyz/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

育児記録アプリ「ぴよログ」の公式 **データフィード API（JSON / schema v1）** を利用して、取得可能なすべての育児記録を Home Assistant へ定期取得・エンティティ化するカスタムインテグレーションです。

> 本インテグレーションは非公式のコミュニティプロジェクトです。API 仕様は [ぴよログ データフィード公式ガイド](https://www.piyolog.com/app/piyolog/data_feed/ja/) に準拠しています。

---

## 主な特徴

- **UI からの安全な登録（ConfigFlow / OptionsFlow / ReconfigureFlow）**
  - Home Assistant の画面からフィード URL を入力するだけでセットアップ完了（複数フィード・複数人対応）。
  - フィード URL（機密情報）はログ・診断情報・`unique_id` には一切出力されません。
  - URL の期限切れや期間変更時は「再構成」からエンティティ ID を維持したまま差し替え可能です。
- **取得期間（`24h` / `3d` / `7d` / `28d`）の自動判定と適切なポーリング**
  - URL の期間表記から公式キャッシュ保持時間を自動判定し、推奨更新間隔を設定します。
- **公式仕様に準拠したエラー・レート制限対策**
  - `429` / `5xx` 発生時は指数バックオフ＋ジッターで自動的に間隔を延長し、復帰後に通常間隔へ戻します。
  - エラー時に「記録 0 件」扱いせず前回取得済みデータを保護しつつ、診断センサー `feed_status` で異常を可視化します。
  - `schema_version` チェック、未知の `type` / フィールドの安全な無視、省略された数値項目を `0` とみなさない処理を実装しています。
- **全 40 種類の記録タイプと集計を網羅**
  - 授乳（母乳・ミルク・搾母乳・搾乳）、睡眠判定・当日睡眠時間、おしっこ・うんち詳細、身体測定（体温・身長・体重・頭囲・胸囲・足左右）、食事・のみもの、健康・生活・メモ・カスタム 1〜10 まで対応。
- **レスポンス付きアクション `piyolog.get_records`**
  - Home Assistant の DB（Recorder 16KB 属性制限）を圧迫せずに、メモリ上の最新スナップショットから条件一致する全レコードをオンデマンドで取得できます。

## 事前準備（ぴよログアプリ側）

1. ぴよログアプリ（管理権限のあるアカウント）で **「設定」＞「データフィード」＞「新しいフィードを作成」** を開きます。
2. 対象の子ども・取得期間（`24時間` / `3日` / `7日` / `28日`）・有効期限を選択して作成します。
3. 詳細画面で **「フィードURLを表示」** から URL をコピーします。

> **注意**: フィード URL はパスワードと同じ機密情報です。公開リポジトリや SNS などに掲載しないでください。

## インストール方法

### 方法 1: HACS（推奨）

1. Home Assistant で **HACS** を開きます。
2. 右上メニューから **「カスタムリポジトリ」** を選択します。
3. 本リポジトリの URL を入力し、カテゴリに **「インテグレーション」** を選んで追加します。
4. **「PiyoLog (ぴよログ)」** をダウンロードし、Home Assistant を再起動します。

### 方法 2: 手動インストール

1. 本リポジトリの `custom_components/piyolog` フォルダを、Home Assistant の `<config>/custom_components/piyolog` へコピーします。
2. Home Assistant を再起動します。

## セットアップ手順

1. Home Assistant の **「設定」＞「デバイスとサービス」＞「統合を追加」** を開きます。
2. **「ぴよログ (PiyoLog)」** を検索して選択します。
3. 以下を入力して送信します：
   - **フィードURL**: ぴよログアプリで発行した URL
   - **表示名**: デバイス名（例: `赤ちゃん`、`ぴよログ` など）
   - **更新間隔（秒）**: 省略時は期間に応じた推奨値を自動適用

| 取得期間 | URL 表記 | 最小許容間隔（キャッシュ時間） | デフォルト更新間隔 |
| --- | --- | --- | --- |
| 24時間 | `24h` | 60秒（1分） | 180秒（3分） |
| 3日 | `3d` | 120秒（2分） | 300秒（5分） |
| 7日 | `7d` | 300秒（5分） | 600秒（10分） |
| 28日 | `28d` | 900秒（15分） | 900秒（15分） |

## 提供エンティティ一覧

### バイナリセンサー
- **睡眠中 (`sleeping`)**: 最新の睡眠関連記録が `Sleep` なら `on`、`WakeUp` なら `off`。

### センサー（デフォルト有効）
- **授乳・ミルク**: 最後の授乳・ミルク、最後の母乳、最後の母乳の側（`left`/`right`）、最後のミルク、最後のミルク量、最後の搾母乳、最後の搾乳、今日のミルク合計量、今日の母乳回数、今日の搾母乳合計量、今日の搾乳合計量、今日の授乳合計回数
- **睡眠・排泄**: 最後に寝た時刻、最後に起きた時刻、今日の睡眠時間、最後のおしっこ、今日のおしっこ回数、最後のうんち（量・かたさ・色を属性に保持）、今日のうんち回数
- **身体測定**: 最新体温、最新体重、最新身長、最新頭囲、最新胸囲、最新足サイズ（左）、最新足サイズ（右）
- **食事・生活・健康・メモ**: 最後の離乳食、最後のごはん、最後のおやつ、最後ののみもの、最後のお風呂、最後のさんぽ、最後のくすり、最後のせき、最後の吐く、最後の発疹、最後のけが、最後の病院、最後の予防接種、最後のできた、最後のその他、最後のメモ、最新の記録（直近 20 件を属性に保持）
- **診断**: フィード状態（`ok` / `rate_limited` / `temporary_error` / `unavailable` / `too_large` / `unsupported_schema`）、取得レコード数

### センサー（デフォルト無効・UI から個別有効化可能）
- **最後のカスタム1〜10 (`last_custom1` 〜 `last_custom10`)**

## サービスアクション: `piyolog.get_records`

メモリ上の最新スナップショットから条件に合う記録一覧をレスポンスデータとして返却します（追加の API 通信は発生しません）。

```yaml
action: piyolog.get_records
data:
  types:
    - Formula
    - BreastFeeding
  limit: 30
response_variable: piyolog_data
```

パラメータ：
- `entry_id`（任意）: 対象フィードの ConfigEntry ID（複数フィード登録時に指定）
- `types`（任意）: 抽出する記録種別のリスト（例: `["Formula", "Poop"]`）
- `limit`（任意）: 返却する最大件数（新しい順、デフォルト `50`、最大 `500`）
